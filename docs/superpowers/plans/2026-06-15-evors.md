# evors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `evors`, a trait-based evolutionary computation crate with a `Genetic` instruction-set, a self-contained ask/tell `EvolutionStrategy`, a `Trial` runner, two built-in strategies (`ClassicPopulation`, `SoftStochastic`/SSEA), and XOR + unit-circle benchmarks.

**Architecture:** Three decoupled core traits. `Genetic` is a descriptor object (not implemented on the genome) defining `random`/`cross`/`mutate`/`gene_dist`. `EvolutionStrategy` carries its genetics as an **associated type** and **owns its genetics value plus a seeded `ChaCha8Rng`**; `next`/`report` take no per-call arguments. A `run` function drives a strategy against a fitness closure until a `Stop` condition, batching evaluations (optionally in parallel). The core stays score-agnostic; scoring helpers (`Fitness`, `Behavior`) are opt-in bounds used by concrete strategies. Strategies are constructed from **CreateInfo structs** (Vulkan-style), not builders.

**Tech Stack:** Rust (edition 2024), `rand` 0.8, `rand_chacha` 0.3, `rayon` (optional `parallel` feature).

use crate::genetic::Genetic;
use crate::strategy::EvolutionStrategy;

/// When to stop a run.
pub enum Stop<S> {
    /// Stop after this many batches (one "generation" per batch).
    Generations(usize),
    /// Stop after this many individual evaluations.
    Trials(usize),
    /// Stop when the predicate over the current best score returns true.
    Until(Box<dyn Fn(&S) -> bool>),
}

/// Run configuration (CreateInfo-style plain struct — no builder).
pub struct RunConfig<S> {
    pub stop: Stop<S>,
    /// Genomes pulled from `next()` per round before evaluation.
    pub batch_size: usize,
}

pub struct Outcome<G, S> {
    pub best_genome: Option<G>,
    pub best_score: Option<S>,
    pub generations: usize,
    pub trials: usize,
}

/// Evaluate a batch of genomes. Sequential build.
#[cfg(not(feature = "parallel"))]
fn evaluate<G, S, F>(batch: Vec<G>, fitness: &F) -> Vec<(G, S)>
where
    F: Fn(&G) -> S,
{
    batch.into_iter().map(|g| { let s = fitness(&g); (g, s) }).collect()
}

/// Drive a self-contained strategy against `fitness` until `cfg.stop`.
/// The strategy owns its genetics and rng, so the runner needs neither.
pub fn run<St, F>(
    cfg: &RunConfig<St::Score>,
    strategy: &mut St,
    fitness: F,
) -> Outcome<<St::Genetic as Genetic>::Genome, St::Score>
where
    St: EvolutionStrategy,
    F: Fn(&<St::Genetic as Genetic>::Genome) -> St::Score + Sync,
    <St::Genetic as Genetic>::Genome: Clone + Send,
    St::Score: Clone + Send,
{
    let mut generations = 0usize;
    let mut trials = 0usize;
    let batch_size = cfg.batch_size.max(1);

    loop {
        // Stop checks BEFORE producing more work.
        match &cfg.stop {
            Stop::Generations(g) if generations >= *g => break,
            Stop::Trials(t) if trials >= *t => break,
            Stop::Until(pred) => {
                if let Some((_, s)) = strategy.best() {
                    if pred(s) { break; }
                }
            }
            _ => {}
        }

        // Ask for a batch against the current strategy snapshot.
        let batch: Vec<<St::Genetic as Genetic>::Genome> =
            (0..batch_size).map(|_| strategy.next()).collect();

        // Evaluate, then report sequentially so steady-state strategies update per-report.
        for (g, s) in evaluate(batch, &fitness) {
            strategy.report(g, s);
            trials += 1;
        }
        generations += 1;
    }

    let (best_genome, best_score) = match strategy.best() {
        Some((g, s)) => (Some(g.clone()), Some(s.clone())),
        None => (None, None),
    };
    Outcome { best_genome, best_score, generations, trials }
}

use crate::genetic::Genetic;

use rand::{Rng, SeedableRng};
use rand_chacha::ChaCha8Rng;

/// CreateInfo for `ClassicPopulation`.
pub struct ClassicPopulationInfo {
    pub pop_size: usize,
    pub tournament: usize,
    pub mutation_rate: f64,
    pub seed: u64,
}

impl Default for ClassicPopulationInfo {
    fn default() -> Self {
        Self { pop_size: 100, tournament: 3, mutation_rate: 0.1, seed: 0 }
    }
}

/// A classic generational GA. `Score = f64` (higher is better).
/// Buffers a generation of reports, then tournament-selects parents and
/// produces offspring via cross + mutate. Owns its genetics and rng.
pub struct ClassicPopulation<X: Genetic> {
    genetics: X,
    rng: ChaCha8Rng,
    pop_size: usize,
    tournament: usize,
    mutation_rate: f64,
    current: Vec<(X::Genome, f64)>,
    pending: usize,
    best: Option<(X::Genome, f64)>,
    initialized: bool,
}

impl<X: Genetic> ClassicPopulation<X> {
    pub fn new(genetics: X, info: ClassicPopulationInfo) -> Self {
        Self {
            genetics,
            rng: ChaCha8Rng::seed_from_u64(info.seed),
            pop_size: info.pop_size.max(2),
            tournament: info.tournament.max(1),
            mutation_rate: info.mutation_rate.clamp(0.0, 1.0),
            current: Vec::new(),
            pending: 0,
            best: None,
            initialized: false,
        }
    }

    /// Tournament selection from `current` (must be non-empty). Associated fn
    /// over explicit fields to keep borrows disjoint.
    fn select(current: &[(X::Genome, f64)], tournament: usize, rng: &mut ChaCha8Rng) -> X::Genome {
        let mut best: Option<&(X::Genome, f64)> = None;
        for _ in 0..tournament {
            let cand = &current[rng.gen_range(0..current.len())];
            if best.map_or(true, |b| cand.1 > b.1) {
                best = Some(cand);
            }
        }
        best.unwrap().0.clone()
    }
}

impl<X: Genetic> EvolutionStrategy for ClassicPopulation<X> {
    type Genetic = X;
    type Score = f64;

    fn next(&mut self) -> X::Genome {
        self.pending += 1;
        if !self.initialized || self.current.is_empty() {
            if self.pending >= self.pop_size {
                self.initialized = true;
            }
            return self.genetics.random(&mut self.rng);
        }
        let p1 = Self::select(&self.current, self.tournament, &mut self.rng);
        let p2 = Self::select(&self.current, self.tournament, &mut self.rng);
        let child = self.genetics.cross(&p1, &p2, &mut self.rng);
        if self.rng.gen_bool(self.mutation_rate) {
            self.genetics.mutate(&child, &mut self.rng)
        } else {
            child
        }
    }

    fn report(&mut self, genome: X::Genome, score: f64) {
        if self.best.as_ref().map_or(true, |(_, s)| score > *s) {
            self.best = Some((genome.clone(), score));
        }
        self.current.push((genome, score));
        if self.current.len() > self.pop_size {
            let overflow = self.current.len() - self.pop_size;
            self.current.drain(0..overflow);
        }
        if self.pending >= self.pop_size {
            self.pending = 0; // begin a new generation of asks
        }
    }

    fn best(&self) -> Option<(&X::Genome, &f64)> {
        self.best.as_ref().map(|(g, s)| (g, s))
    }
}

## Task 7: `SoftStochastic` (SSEA)

**Files:**
- Create/replace: `src/strategies/soft.rs`
- Test: inline `#[cfg(test)]` in `src/strategies/soft.rs`

SSEA kernel (tunable constants in `SoftStochasticInfo`):
- **`report`:** push the evaluated individual, update `best`, then if `pool.len() > target` run the soft cull **in place** (the strategy owns `genetics` + `rng`, so this is the natural home — no deferral, no over-capacity window).
- **Soft cull:** for each member `combined = (1-w)*norm_fitness + w*norm_novelty`, survival `p = combined^pressure`, `pressure = pool/target`; retain stochastically via `self.rng`; always keep the current best.
- **`next`:** `ratio = pool/target`; `p_random = (1 - ratio).clamp(0.05, 0.9)`; otherwise Boltzmann-pick a parent by `exp(fitness/temperature)` and split mutate/cross/replay 0.6/0.3/0.1.
- **Novelty:** mean `gene_dist` to up-to-`knn` nearest neighbors, normalized to [0,1] over the pool.

> Borrow-checker note: `boltzmann_pick` and `genetic_novelty` are **associated fns** taking explicit `&[Member<_>]` / `&X` / `&mut ChaCha8Rng` so they never borrow all of `self` alongside `self.rng`.

/// Stochastic Soft Evolution Algorithm: steady-state, soft-culling, no hard
/// cutoffs. `Score: Fitness`. v1 novelty is genetic (`gene_dist`). Owns its
/// genetics and rng.
pub struct SoftStochastic<X: Genetic> {
    genetics: X,
    rng: ChaCha8Rng,

    temperature: f64,
    novelty_weight: f64,
    knn: usize,

    pub fn new(genetics: X, info: SoftStochasticInfo) -> Self {
        Self {
            genetics,
            rng: ChaCha8Rng::seed_from_u64(info.seed),
            target: info.target.max(2),
            temperature: info.temperature.max(1e-6),
            novelty_weight: info.novelty_weight.clamp(0.0, 1.0),
            knn: info.knn.max(1),
            pool: Vec::new(),
            best: None,
        }
    }

    /// Boltzmann (softmax over fitness/temperature) selection index.
    fn boltzmann_pick(pool: &[Member<X::Genome>], temperature: f64, rng: &mut ChaCha8Rng) -> usize {
        let max_f = pool.iter().map(|m| m.fitness).fold(f64::MIN, f64::max);
        let weights: Vec<f64> = pool
            .iter()
            .map(|m| ((m.fitness - max_f) / temperature).exp())
            .collect();
        let total: f64 = weights.iter().sum();
        let mut pick = rng.gen::<f64>() * total;
        for (i, w) in weights.iter().enumerate() {
            pick -= w;
            if pick <= 0.0 {
                return i;
            }
        }
        pool.len() - 1
    }

    /// Mean gene_dist from `genome` to its up-to-knn nearest pool neighbors.
    /// `skip` excludes one index (a member measuring against itself).
    fn genetic_novelty(
        genetics: &X,
        pool: &[Member<X::Genome>],
        knn: usize,
        genome: &X::Genome,
        skip: Option<usize>,
    ) -> f64 {
        let mut dists: Vec<f64> = pool
            .iter()
            .enumerate()
            .filter(|(i, _)| Some(*i) != skip)
            .map(|(_, m)| genetics.gene_dist(genome, &m.genome))
            .collect();
        if dists.is_empty() {
            return 0.0;
        }
        dists.sort_by(|a, b| a.partial_cmp(b).unwrap());
        let k = knn.min(dists.len());
        dists.iter().take(k).sum::<f64>() / k as f64
    }

    /// Soft cull, run from `report` when over capacity. Uses owned genetics for
    /// genuine genetic novelty and owned rng for reproducibility.
    fn soft_cull(&mut self) {
        let (min_f, max_f) = self
            .pool
            .iter()
            .fold((f64::MAX, f64::MIN), |(lo, hi), m| (lo.min(m.fitness), hi.max(m.fitness)));
        let fspan = (max_f - min_f).max(1e-9);

        let novelty: Vec<f64> = (0..self.pool.len())
            .map(|i| {
                Self::genetic_novelty(&self.genetics, &self.pool, self.knn, &self.pool[i].genome, Some(i))
            })
            .collect();
        let (min_n, max_n) = novelty
            .iter()
            .fold((f64::MAX, f64::MIN), |(lo, hi), n| (lo.min(*n), hi.max(*n)));
        let nspan = (max_n - min_n).max(1e-9);

        let pressure = (self.pool.len() as f64 / self.target as f64).max(1e-3);
        let w = self.novelty_weight;
        let best_fit = self.best.as_ref().map(|(_, f)| *f);

        let drained: Vec<Member<X::Genome>> = std::mem::take(&mut self.pool);
        let mut survivors: Vec<Member<X::Genome>> = Vec::with_capacity(drained.len());
        let mut kept_best = false;
        for (i, m) in drained.into_iter().enumerate() {
            // Keep exactly one copy of the global best unconditionally.
            if !kept_best && best_fit.map_or(false, |bf| (m.fitness - bf).abs() < f64::EPSILON) {
                kept_best = true;
                survivors.push(m);
                continue;
            }
            let nf = (m.fitness - min_f) / fspan;
            let nn = (novelty[i] - min_n) / nspan;
            let combined = ((1.0 - w) * nf + w * nn).clamp(0.0, 1.0);
            let p_survive = combined.powf(pressure).clamp(0.0, 1.0);
            if self.rng.gen_bool(p_survive) {
                survivors.push(m);
            }
        }
        self.pool = survivors;
    }
}

impl<X: Genetic> EvolutionStrategy for SoftStochastic<X> {
    type Genetic = X;
    type Score = f64;

    fn next(&mut self) -> X::Genome {
        if self.pool.is_empty() {
            return self.genetics.random(&mut self.rng);
        }
        let ratio = self.pool.len() as f64 / self.target as f64;
        let p_random = (1.0 - ratio).clamp(0.05, 0.9);
        if self.rng.gen_bool(p_random) {
            return self.genetics.random(&mut self.rng);
        }
        let pi = Self::boltzmann_pick(&self.pool, self.temperature, &mut self.rng);
        let parent = self.pool[pi].genome.clone();
        let action: f64 = self.rng.gen();
        if action < 0.6 {
            self.genetics.mutate(&parent, &mut self.rng)
        } else if action < 0.9 {
            let oi = Self::boltzmann_pick(&self.pool, self.temperature, &mut self.rng);
            let other = self.pool[oi].genome.clone();
            self.genetics.cross(&parent, &other, &mut self.rng)
        } else {
            parent // replay
        }
    }

    fn report(&mut self, genome: X::Genome, score: f64) {
        let fit = score.fitness();
        if self.best.as_ref().map_or(true, |(_, s)| fit > *s) {
            self.best = Some((genome.clone(), fit));
        }
        self.pool.push(Member { genome, fitness: fit });
        if self.pool.len() > self.target {
            self.soft_cull();
        }
    }

    fn best(&self) -> Option<(&X::Genome, &f64)> {
        self.best.as_ref().map(|(g, s)| (g, s))
    }
}

/// Whole unit circle is optimal: fitness = 1 - (x^2 + y^2 - 1)^2.
fn ring_fitness(p: &Point) -> f64 {
    let r2 = p.x * p.x + p.y * p.y;
    1.0 - (r2 - 1.0).powi(2)
}

/// Number of populated angle sectors (out of `sectors`) among high-fitness points.
fn sector_coverage(points: &[Point], sectors: usize, fit_threshold: f64) -> usize {
    let mut hit = vec![false; sectors];
    for p in points {
        if ring_fitness(p) >= fit_threshold {
            let mut ang = p.y.atan2(p.x); // -pi..pi
            if ang < 0.0 { ang += std::f64::consts::TAU; }
            let idx = ((ang / std::f64::consts::TAU) * sectors as f64) as usize % sectors;
            hit[idx] = true;
        }
    }
    hit.iter().filter(|b| **b).count()
}

## Notes for the Executor

- All RNG is owned by each strategy (a seeded `ChaCha8Rng` set from its CreateInfo `seed`); never call `rand::thread_rng()` inside strategies — runs must be reproducible.
- `Genetic` is implemented on a descriptor struct, never on the genome type.
- `EvolutionStrategy` carries genetics as an associated type and takes no per-call args; the genome is `<St::Genetic as Genetic>::Genome`.
- Strategies are built via CreateInfo structs (`..Default::default()`), not builder chains.
- Keep helper fns that need both pool data and `rng` as **associated fns over explicit field refs** to avoid borrowing all of `self` while `self.rng` is mutably borrowed.
- The core (`genetic`, `strategy`, `trial`) stays score-agnostic. Fitness/novelty logic lives only in `strategies/*`.
- SSEA constants (`temperature`, `novelty_weight`, `knn`, `target`) are tunable; if a benchmark is flaky, tune these rather than weakening an assertion.
