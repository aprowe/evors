> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `evors`, a trait-based evolutionary computation crate with a `Genetic` instruction-set, an ask/tell `EvolutionStrategy`, a `Trial` runner, two built-in strategies (`ClassicPopulation`, `SoftStochastic`/SSEA), and XOR + unit-circle benchmarks.

**Architecture:** Three decoupled core traits. `Genetic` is a descriptor object (not implemented on the genome) defining `random`/`cross`/`mutate`/`gene_dist`. `EvolutionStrategy` owns its population and exposes an ask/tell interface (`next`/`report`/`best`) with a strategy-defined associated `Score`. A `Trial::run` function drives a strategy against a fitness closure until a `Stop` condition, batching evaluations (optionally in parallel). The core stays score-agnostic; scoring helpers (`Fitness`, `Behavior`) are opt-in bounds used by concrete strategies.

**Tech Stack:** Rust (edition 2024), `rand` 0.8, `rand_chacha` 0.3, `rayon` (optional `parallel` feature).

```rust
use crate::genetic::Genetic;
```

```rust
/// When to stop a run.
pub enum Stop<S> {
    /// Stop after this many batches (one "generation" per batch).
    Generations(usize),
    /// Stop after this many individual evaluations.
    Trials(usize),
    /// Stop when the predicate over the current best score returns true.
    Until(Box<dyn Fn(&S) -> bool>),
}

pub struct RunConfig<S> {
    pub stop: Stop<S>,
    /// Genomes pulled from `next()` per round before evaluation.
    pub batch_size: usize,
    pub seed: Option<u64>,
}

impl<S> RunConfig<S> {
    pub fn new(stop: Stop<S>) -> Self {
        Self { stop, batch_size: 1, seed: None }
    }
    pub fn batch_size(mut self, n: usize) -> Self {
        self.batch_size = n.max(1);
        self
    }
    pub fn seed(mut self, seed: u64) -> Self {
        self.seed = Some(seed);
        self
    }
}

pub struct Outcome<G, S> {
    pub best_genome: Option<G>,
    pub best_score: Option<S>,
    pub generations: usize,
    pub trials: usize,
}

/// Evaluate a batch of genomes. Sequential build.
#[cfg(not(feature = "parallel"))]
fn evaluate<G, S, F>(batch: Vec<G>, fitness: &F) -> Vec<(G, S)>
where
    F: Fn(&G) -> S,
{
    batch.into_iter().map(|g| { let s = fitness(&g); (g, s) }).collect()
}

pub fn run<X, St, F, S>(
    cfg: &RunConfig<S>,
    genetics: &X,
    strategy: &mut St,
    fitness: F,
) -> Outcome<X::Genome, S>
where
    X: Genetic,
    St: EvolutionStrategy<X, Score = S>,
    F: Fn(&X::Genome) -> S + Sync,
    X::Genome: Clone + Send,
    S: Clone + Send,
{
    let mut rng = match cfg.seed {
        Some(s) => ChaCha8Rng::seed_from_u64(s),
        None => ChaCha8Rng::from_entropy(),
    };
    let mut generations = 0usize;
    let mut trials = 0usize;

    loop {
        // Stop checks BEFORE producing more work.
        match &cfg.stop {
            Stop::Generations(g) if generations >= *g => break,
            Stop::Trials(t) if trials >= *t => break,
            Stop::Until(pred) => {
                if let Some((_, s)) = strategy.best() {
                    if pred(s) { break; }
                }
            }
            _ => {}
        }

        // Ask for a batch against the current strategy snapshot.
        let batch: Vec<X::Genome> =
            (0..cfg.batch_size).map(|_| strategy.next(genetics, &mut rng)).collect();

        // Evaluate, then report sequentially so steady-state strategies update per-report.
        for (g, s) in evaluate(batch, &fitness) {
            strategy.report(g, s);
            trials += 1;
        }
        generations += 1;
    }

    let (best_genome, best_score) = match strategy.best() {
        Some((g, s)) => (Some(g.clone()), Some(s.clone())),
        None => (None, None),
    };
    Outcome { best_genome, best_score, generations, trials }
}
```

```rust
use crate::genetic::Genetic;
use crate::strategy::EvolutionStrategy;
use rand::Rng;

/// A classic generational GA. Score = f64 (higher is better).
/// Buffers one generation of reports, then tournament-selects parents and
/// produces the next generation via cross + mutate.
pub struct ClassicPopulation<G> {
    pop_size: usize,
    tournament: usize,
    mutation_rate: f64,
    /// Current generation, evaluated as reports arrive.
    current: Vec<(G, f64)>,
    /// Genomes handed out but not yet reported this generation.
    pending: usize,
    /// Best ever seen.
    best: Option<(G, f64)>,
    /// Seed pool for the very first `next` calls (random genomes).
    initialized: bool,
}

impl<G: Clone> ClassicPopulation<G> {
    pub fn new(pop_size: usize) -> Self {
        Self {
            pop_size: pop_size.max(2),
            tournament: 3,
            mutation_rate: 0.1,
            current: Vec::new(),
            pending: 0,
            best: None,
            initialized: false,
        }
    }

    pub fn tournament(mut self, k: usize) -> Self { self.tournament = k.max(1); self }
    pub fn mutation_rate(mut self, r: f64) -> Self { self.mutation_rate = r.clamp(0.0, 1.0); self }

    /// Tournament selection from `current` (must be non-empty).
    fn select<'a>(&'a self, rng: &mut impl Rng) -> &'a G {
        let mut best: Option<&(G, f64)> = None;
        for _ in 0..self.tournament {
            let cand = &self.current[rng.gen_range(0..self.current.len())];
            if best.map_or(true, |b| cand.1 > b.1) {
                best = Some(cand);
            }
        }
        &best.unwrap().0
    }
}

impl<X: Genetic> EvolutionStrategy<X> for ClassicPopulation<X::Genome> {
    type Score = f64;

    fn next(&mut self, genetics: &X, rng: &mut impl Rng) -> X::Genome {
        self.pending += 1;
        // Until we have a full evaluated generation, emit random genomes.
        if !self.initialized || self.current.is_empty() {
            if self.pending >= self.pop_size {
                self.initialized = true;
            }
            return genetics.random(rng);
        }
        // Produce offspring from the current evaluated generation.
        let p1 = self.select(rng).clone();
        let p2 = self.select(rng).clone();
        let child = genetics.cross(&p1, &p2, rng);
        if rng.gen_bool(self.mutation_rate) {
            genetics.mutate(&child, rng)
        } else {
            child
        }
    }

    fn report(&mut self, genome: X::Genome, score: f64) {
        if self.best.as_ref().map_or(true, |(_, s)| score > *s) {
            self.best = Some((genome.clone(), score));
        }
        // Stage into the next generation buffer.
        // When a full generation has been reported, it becomes `current`.
        // We accumulate into a temporary held in `current` once `pending` rolls over.
        self.current.push((genome, score));
        if self.current.len() > self.pop_size {
            // Keep only the most recent pop_size reports as the "current" generation.
            let overflow = self.current.len() - self.pop_size;
            self.current.drain(0..overflow);
        }
        if self.pending >= self.pop_size {
            self.pending = 0; // start a new generation of asks
        }
    }

    fn best(&self) -> Option<(&X::Genome, &f64)> {
        self.best.as_ref().map(|(g, s)| (g, s))
    }
}
```

## Task 7: `SoftStochastic` (SSEA)

**Files:**
- Create/replace: `src/strategies/soft.rs`
- Test: inline `#[cfg(test)]` in `src/strategies/soft.rs`

SSEA kernel (tunable constants):
- `report`: append the evaluated individual (fitness only) and update `best`. No culling here — `report` has no `genetics`, so it cannot compute `gene_dist`.
- `next`: FIRST, if `pool.len() > target`, run the soft cull (which has `genetics`): for each member compute `combined = (1-w)*norm_fitness + w*norm_novelty`, survival `p = combined^pressure`, `pressure = pool/target`; retain stochastically using the passed `rng`; always keep the current best. THEN pick the action: `ratio = pool/target`; `p_random = (1 - ratio).clamp(0.05, 0.9)`; otherwise Boltzmann-pick a parent by `exp(fitness/temperature)` and split mutate/cross/replay 0.6/0.3/0.1. Novelty = mean `gene_dist` to up-to-`knn` nearest neighbors, normalized to [0,1] over the pool.

This keeps culling reproducible (no `thread_rng`) and gives it real genetic-novelty access.

```rust
use crate::genetic::Genetic;
use crate::strategy::{EvolutionStrategy, Fitness};
use rand::Rng;

struct Member<G> {
    genome: G,
    fitness: f64,
}

/// Stochastic Soft Evolution Algorithm: steady-state, soft-culling, no hard
/// cutoffs. Requires `Score: Fitness`. Novelty in v1 is genetic (gene_dist).
pub struct SoftStochastic<G> {
    target: usize,
    temperature: f64,
    novelty_weight: f64, // w in [0,1]
    knn: usize,
    pool: Vec<Member<G>>,
    best: Option<(G, f64)>,
}

impl<G: Clone> SoftStochastic<G> {
    pub fn new(target: usize) -> Self {
        Self {
            target: target.max(2),
            temperature: 0.2,
            novelty_weight: 0.5,
            knn: 5,
            pool: Vec::new(),
            best: None,
        }
    }
    pub fn temperature(mut self, t: f64) -> Self { self.temperature = t.max(1e-6); self }
    pub fn novelty_weight(mut self, w: f64) -> Self { self.novelty_weight = w.clamp(0.0, 1.0); self }
    pub fn knn(mut self, k: usize) -> Self { self.knn = k.max(1); self }

    /// Boltzmann (softmax over fitness/temperature) selection index.
    fn boltzmann_pick(&self, rng: &mut impl Rng) -> usize {
        let max_f = self.pool.iter().map(|m| m.fitness).fold(f64::MIN, f64::max);
        let weights: Vec<f64> = self
            .pool
            .iter()
            .map(|m| ((m.fitness - max_f) / self.temperature).exp())
            .collect();
        let total: f64 = weights.iter().sum();
        let mut pick = rng.gen::<f64>() * total;
        for (i, w) in weights.iter().enumerate() {
            pick -= w;
            if pick <= 0.0 {
                return i;
            }
        }
        self.pool.len() - 1
    }

    /// Mean gene_dist from `genome` to its up-to-knn nearest pool neighbors.
    /// `skip` excludes one index (a member measuring against itself).
    fn genetic_novelty<X>(&self, genetics: &X, genome: &G, skip: Option<usize>) -> f64
    where
        X: Genetic<Genome = G>,
    {
        let mut dists: Vec<f64> = self
            .pool
            .iter()
            .enumerate()
            .filter(|(i, _)| Some(*i) != skip)
            .map(|(_, m)| genetics.gene_dist(genome, &m.genome))
            .collect();
        if dists.is_empty() {
            return 0.0;
        }
        dists.sort_by(|a, b| a.partial_cmp(b).unwrap());
        let k = self.knn.min(dists.len());
        dists.iter().take(k).sum::<f64>() / k as f64
    }

    /// Soft cull. Runs only when over capacity. Uses `genetics` for genuine
    /// genetic novelty and the passed `rng` for reproducibility.
    fn soft_cull<X>(&mut self, genetics: &X, rng: &mut impl Rng)
    where
        X: Genetic<Genome = G>,
    {
        // Normalize fitness across the pool.
        let (min_f, max_f) = self
            .pool
            .iter()
            .fold((f64::MAX, f64::MIN), |(lo, hi), m| (lo.min(m.fitness), hi.max(m.fitness)));
        let fspan = (max_f - min_f).max(1e-9);

        // Per-member novelty, then normalize.
        let novelty: Vec<f64> = (0..self.pool.len())
            .map(|i| {
                let g = self.pool[i].genome.clone();
                self.genetic_novelty(genetics, &g, Some(i))
            })
            .collect();
        let (min_n, max_n) = novelty
            .iter()
            .fold((f64::MAX, f64::MIN), |(lo, hi), n| (lo.min(*n), hi.max(*n)));
        let nspan = (max_n - min_n).max(1e-9);

        let pressure = (self.pool.len() as f64 / self.target as f64).max(1e-3);
        let w = self.novelty_weight;
        let best_fit = self.best.as_ref().map(|(_, f)| *f);

        let mut survivors: Vec<Member<G>> = Vec::with_capacity(self.pool.len());
        let drained: Vec<Member<G>> = std::mem::take(&mut self.pool);
        let mut kept_best = false;
        for (i, m) in drained.into_iter().enumerate() {
            // Keep exactly one copy of the global best unconditionally.
            if !kept_best && best_fit.map_or(false, |bf| (m.fitness - bf).abs() < f64::EPSILON) {
                kept_best = true;
                survivors.push(m);
                continue;
            }
            let nf = (m.fitness - min_f) / fspan;
            let nn = (novelty[i] - min_n) / nspan;
            let combined = ((1.0 - w) * nf + w * nn).clamp(0.0, 1.0);
            let p_survive = combined.powf(pressure).clamp(0.0, 1.0);
            if rng.gen_bool(p_survive) {
                survivors.push(m);
            }
        }
        self.pool = survivors;
    }
}

impl<X> EvolutionStrategy<X> for SoftStochastic<X::Genome>
where
    X: Genetic,
{
    type Score = f64;

    fn next(&mut self, genetics: &X, rng: &mut impl Rng) -> X::Genome {
        if self.pool.is_empty() {
            return genetics.random(rng);
        }
        // Soft cull when over capacity (this is where genetics is available).
        if self.pool.len() > self.target {
            self.soft_cull(genetics, rng);
        }
        if self.pool.is_empty() {
            return genetics.random(rng);
        }
        let ratio = self.pool.len() as f64 / self.target as f64;
        let p_random = (1.0 - ratio).clamp(0.05, 0.9);
        if rng.gen_bool(p_random) {
            return genetics.random(rng);
        }
        let parent = self.pool[self.boltzmann_pick(rng)].genome.clone();
        let action = rng.gen::<f64>();
        if action < 0.6 {
            genetics.mutate(&parent, rng)
        } else if action < 0.9 {
            let other = self.pool[self.boltzmann_pick(rng)].genome.clone();
            genetics.cross(&parent, &other, rng)
        } else {
            parent // replay
        }
    }

    fn report(&mut self, genome: X::Genome, score: f64) {
        let fit = score.fitness();
        if self.best.as_ref().map_or(true, |(_, s)| fit > *s) {
            self.best = Some((genome.clone(), fit));
        }
        self.pool.push(Member { genome, fitness: fit });
    }

    fn best(&self) -> Option<(&X::Genome, &f64)> {
        self.best.as_ref().map(|(g, s)| (g, s))
    }
}
```

```rust
/// Whole unit circle is optimal: fitness = 1 - (x^2 + y^2 - 1)^2.
fn ring_fitness(p: &Point) -> f64 {
    let r2 = p.x * p.x + p.y * p.y;
    1.0 - (r2 - 1.0).powi(2)
}

/// Number of populated angle sectors (out of `sectors`) among high-fitness points.
fn sector_coverage(points: &[Point], sectors: usize, fit_threshold: f64) -> usize {
    let mut hit = vec![false; sectors];
    for p in points {
        if ring_fitness(p) >= fit_threshold {
            let mut ang = p.y.atan2(p.x); // -pi..pi
            if ang < 0.0 { ang += std::f64::consts::TAU; }
            let idx = ((ang / std::f64::consts::TAU) * sectors as f64) as usize % sectors;
            hit[idx] = true;
        }
    }
    hit.iter().filter(|b| **b).count()
}
```

## Notes for the Executor

- All RNG flows through `&mut impl Rng`; never call `rand::thread_rng()` inside strategies — runs must be reproducible from `RunConfig::seed`.
- `Genetic` is implemented on a descriptor struct, never on the genome type.
- The core (`genetic`, `strategy`, `trial`) must stay score-agnostic. Fitness/novelty logic lives only in `strategies/*`.
- SSEA constants (`temperature`, `novelty_weight`, `knn`, `target`) are tunable; if a benchmark is flaky, tune these rather than weakening an assertion.
